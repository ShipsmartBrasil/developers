# Ítems

- [Volver al README del idioma](README.md)

## Visión general
- Gestiona ítems para cotizaciones, borradores y remesas.

## Convenciones
- `Content-Type: application/json`
- La consulta usa `items[skus][]`.
- Alta/actualización/eliminación son asíncronas.

## Endpoints
- `GET /v1/item`
- `POST /v1/item`
- `PUT /v1/item`
- `DELETE /v1/item`
