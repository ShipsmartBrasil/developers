## Como usar
O uso da API deve começar pelo fluxo principal de cotação e remessa:

- [Cotação](api-cotacao-v1.md) ou [Cotação V2](api-cotacao-v2.md)
- [Remessa](api-remessa-v1.md) ou [Remessa V2](api-remessa-v2.md)
- [Cotação & Remessa: v1 vs v2](api-comparativo-cotacao-remessa.md)
- [Buscar os documentos da remessa](api-documentos.md)
- [Agendar coleta junto ao transportador](api-agendamento.md)
- [Acompanhar a remessa](api-rastreio.md)

Outras formas de fazer remessa:

- [Manifesto](api-manifesto.md): cotação & remessa síncrona diretamente no transportador
- [Rascunho](api-rascunho.md): cotação & remessa assíncrona

APIs de apoio:

- [Caixa](api-caixa-v1.md)
