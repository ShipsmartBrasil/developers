# Programmazione ritiro

- [Torna al README della lingua](README.md)

## Panoramica
- Crea, consulta e annulla le programmazioni di ritiro collegate alla spedizione.

## Convenzioni
- Date nel formato `Y-m-d`.
- Orari nel formato `H:i:s`.

## Endpoint
- `POST /v1/schedule`
- `GET /v1/schedule/{shipping}`
- `DELETE /v1/schedule/{shipping}/{reason}`
