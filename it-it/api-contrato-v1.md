# Contratto

- [Torna al README della lingua](README.md)

## Panoramica
- Elenca i contratti disponibili per l'utente autenticato.

## Convenzioni
- `Content-Type: application/json`
- La lista può essere filtrata per `status`.

## Flusso d'uso
1. Autentica l'utente.
2. Elenca i contratti disponibili.
3. Usa il codice del contratto nella quotazione o spedizione.

## Endpoint
- `GET /v1/contract`
