## Come usare
L'uso dell'API deve iniziare dal flusso principale di quotazione e spedizione:

- [Quotazione](api-cotacao-v1.md) o [Quotazione V2](api-cotacao-v2.md)
- [Spedizione](api-remessa-v1.md) o [Spedizione V2](api-remessa-v2.md)
- [Quotazione & Spedizione: v1 vs v2](api-comparativo-cotacao-remessa.md)
- [Recuperare i documenti della spedizione](api-documentos.md)
- [Programmare il ritiro con il trasportatore](api-agendamento.md)
- [Monitorare la spedizione](api-rastreio.md)

Altri modi per creare spedizioni:

- [Manifesto](api-manifesto.md): quotazione & spedizione sincrone direttamente con il trasportatore
- [Bozza](api-rascunho.md): quotazione & spedizione asincrone

API di supporto:

- [Scatola](api-caixa-v1.md)
- [Articolo](api-itens-v1.md)
- [Contratto](api-contrato-v1.md)
