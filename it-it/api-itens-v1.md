# Articoli

- [Torna al README della lingua](README.md)

## Panoramica
- Gestisce gli articoli usati in quotazioni, bozze e spedizioni.

## Convenzioni
- `Content-Type: application/json`
- La consulta usa `items[skus][]`.

## Flusso d'uso
1. Elenca gli articoli già registrati.
2. Registra gli articoli base.
3. Aggiorna gli articoli quando cambiano dimensione, peso o classificazione.
4. Rimuovi gli articoli obsoleti.

## Endpoint
- `GET /v1/item`
- `POST /v1/item`
- `PUT /v1/item`
- `DELETE /v1/item`
