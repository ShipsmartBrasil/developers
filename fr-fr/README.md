## Comment utiliser
L'utilisation de l'API doit commencer par le flux principal de devis et d'expédition :

- [Devis](api-cotacao-v1.md) ou [Devis V2](api-cotacao-v2.md)
- [Expédition](api-remessa-v1.md) ou [Expédition V2](api-remessa-v2.md)
- [Devis & Expédition : v1 vs v2](api-comparativo-cotacao-remessa.md)
- [Récupérer les documents d'expédition](api-documentos.md)
- [Planifier la collecte auprès du transporteur](api-agendamento.md)
- [Suivre l'expédition](api-rastreio.md)

Autres façons de créer des expéditions :

- [Manifesto](api-manifesto.md) : devis & expédition synchrones directement auprès du transporteur
- [Brouillon](api-rascunho.md) : devis & expédition asynchrones

APIs de support :

- [Colis](api-caixa-v1.md)
- [Article](api-itens-v1.md)
- [Contrat](api-contrato-v1.md)
