## Como usar
1. Comece por [Cotação](api-cotacao-v1.md) ou [Cotação V2](api-cotacao-v2.md).
2. Siga para [Remessa](api-remessa-v1.md) ou [Remessa V2](api-remessa-v2.md).
3. Leia o [comparativo entre cotação & remessa: v1 vs v2](api-comparativo-cotacao-remessa.md) para entender quando usar cada versão.
4. Consulte [Documentos de Remessa](api-documentos.md) para pegar os documentos gerados da sua remessa.
5. Consulte o [Rastreio da Remessa](api-rastreio.md) para acompanhar o andamento da sua remessa.
6. Use [Agendamento da Coleta](api-agendamento.md) para especificar o dia e horário de coleta do seu pacote.
7. Use [Manifesto](api-manifesto.md) quando você precisar gerar a remessa de forma sincrona.
8. Cadastre suas [Caixas](api-caixa-v1.md) e [Itens](api-itens-v1.md) para usar na Cotação & Remessa.
9. Consulte os seus [Contratos](api-contrato-v1.md).

## Observação
- A documentação está organizada por fluxo para facilitar a integração externa.
- Quando houver divergência entre exemplos e regras, a fonte de verdade é o código analisado.
