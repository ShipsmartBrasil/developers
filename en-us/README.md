## How to use
API usage should start with the main quotation and shipping flow:

- [Quotation](api-cotacao-v1.md) or [Quotation V2](api-cotacao-v2.md)
- [Shipping](api-remessa-v1.md) or [Shipping V2](api-remessa-v2.md)
- [Quotation & Shipping: v1 vs v2](api-comparativo-cotacao-remessa.md)
- [Retrieve the shipping documents](api-documentos.md)
- [Schedule pickup with the carrier](api-agendamento.md)
- [Track the shipment](api-rastreio.md)

Other ways to create shipments:

- [Manifest](api-manifesto.md): synchronous quotation & shipping directly with the carrier
- [Draft](api-rascunho.md): asynchronous quotation & shipping

Support APIs:

- [Box](api-caixa-v1.md)
- [Item](api-itens-v1.md)
- [Contract](api-contrato-v1.md)
